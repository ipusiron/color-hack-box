[Development] RGB vectors and color similarity

Since RGB consists of three values ​​(R, G, B),3d vector It can be understood as. This allows you to determine how "close" or "far" two colors are.calculated mathematically can.

🧮 Represent colors as vectors

For example, red rgb(255, 0, 0) is a vector (255, 0, 0) It can be expressed as

red = (255, 0, 0)
blue = (0, 0, 255)
orange = (255, 128, 0)

📐 How to measure color similarity

euclidean distance

Straight line distance between two points. The value isThe smaller the more similar。

d = √((R₁-R₂)² + (G₁-G₂)² + (B₁-B₂)²)
cosine similarity

Closeness of vector direction.The closer it is to 1, the more similar it is.(range -1 to 1).

cos θ = (A·B) / (|A| × |B|)

Suitable for ignoring differences in brightness and comparing the direction of color.
