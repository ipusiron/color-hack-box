RGBカラースペース

RGB色空間を3次元ベクトルとして視覚化し、色の構成を学びましょう。

RGBとは？

RGBは、Red（赤）、Green（緑）、Blue（青）の3つの光の原色を組み合わせて色を表現するモデルです。

💡 加法混色

RGBは加法混色の原理に基づいています。3つの光をすべて最大（255）にすると白になり、すべて0にすると黒になります。

RGB 3Dカラーキューブ

RGBの色空間は3次元の立方体（キューブ）として表現できます。各軸がR、G、Bに対応し、キューブ内の位置が色を表します。

【発展】RGBベクトルと色の類似度

RGBは3つの値（R, G, B）で構成されるため、3次元ベクトルとして捉えることができます。これにより、2つの色がどれだけ「近い」か「遠い」かを数学的に計算できます。

🧮 色をベクトルとして表現

例えば、赤色 rgb(255, 0, 0) はベクトル (255, 0, 0) として表せます。

赤 = (255, 0, 0)
青 = (0, 0, 255)
オレンジ = (255, 128, 0)

📐 色の類似度を測る方法

ユークリッド距離

2点間の直線距離。値が小さいほど似ている。

d = √((R₁-R₂)² + (G₁-G₂)² + (B₁-B₂)²)
コサイン類似度

ベクトルの向きの近さ。1に近いほど似ている（-1〜1の範囲）。

cos θ = (A·B) / (|A| × |B|)

明るさの違いを無視し、色味の方向性を比較するのに適しています。
