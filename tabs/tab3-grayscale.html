無彩色・グレースケール

彩度が0の世界を探索しましょう。白・黒・グレーの奥深さを学びます。

無彩色とは？

無彩色とは、彩度が0%の色のことで、色相を持たない色です。白・黒・グレーのみが該当し、明度（Lightness）のみで表現されます。

無彩色のグレースケール（明度0%〜100%）

無彩色の特徴

  • 色相がない：どの色相環の位置にも属さない
  • 彩度が0%：鮮やかさがまったくない状態
  • 明度のみで変化：黒（0%）から白（100%）まで
  • RGB値が等しい：rgb(128, 128, 128)のようにR・G・Bが同じ値
  • どんな色とも相性が良い：有彩色を引き立てる

コントラスト比とアクセシビリティ

Webデザインでは、WCAGアクセシビリティガイドラインに基づいたコントラスト比の確保が重要です。

WCAG 2.2のコントラスト基準

レベル 通常テキスト 大きいテキスト
AA（最低基準） 4.5:1 以上 3:1 以上
AAA（より厳しい基準） 7:1 以上 4.5:1 以上

大きいテキストは、18pt以上の通常文字、または14pt以上の太字が目安です。AA・AAAは文字色の判定基準であり、ページ全体の適合レベルを示すものではありません。

黒または白方向へ段階調整した一案であり、最適な唯一の配色ではありません。

この検査で分かること：指定した2色の相対輝度による比率と、選んだ数値基準を満たすかどうかです。比率は小数第3位まで表示しますが、判定には丸める前の値を使います。

この検査だけでは分からないこと：文字の実際の大きさ・太さ、画像やグラデーション上の最小比率、hover・focus・disabledなど各状態、UI部品が接する色、色以外の識別手段です。結果はページ全体のWCAG適合を証明しません。

非テキスト3:1は、操作に必要なUI部品の視覚情報や、内容理解に必要な図形を、その隣接色と比べる目安です。装飾や非アクティブ部品などには例外があります。

コントラスト比の例

✓ 良い例：白背景 + 黒テキスト（21:1）

色の比率は最大。実際の読みやすさは文字サイズや書体なども含めて確認します。

✓ 良い例：白背景 + 濃いグレー（12.6:1）

通常文字・大きい文字ともAAAの数値基準をクリア。

△ 注意：白背景 + グレー（5.7:1）

AAは通常文字・大きい文字ともクリア。AAAは大きい文字のみクリア。

✗ 悪い例：白背景 + 明るいグレー（2.8:1）

基準を満たさない。読みづらい。

💡 アクセシビリティのヒント

  • 本文テキストは背景色とのコントラスト比を実測する
  • 白・黒の固定ルールに頼らず、実際に使う前景色と背景色の組合せで確認する
  • 重要なボタンやリンクは十分なコントラストを確保
  • 薄いグレーは装飾やボーダーのみに使用し、テキストには避ける

無彩色のカラーコードに注目する

無彩色のカラーコードには、興味深い規則性があります。HEX形式のカラーコードを観察してみましょう。

無彩色の特徴的なパターン

無彩色のHEXコードは、同じ数字やアルファベットが並ぶパターンになります。これは、RGB値が等しいためです。

# 88 88 88
↑ R (赤) ↑ G (緑) ↑ B (青)

無彩色では、R・G・Bの値がすべて同じになります

16進数と明度の関係

HEXコードは16進数で表現されます。0〜Fの16種類の文字を使い、以下のような対応関係があります：

0に近いほど暗く（明度が低い）、Fに近いほど明るく（明度が高い）なります

💡 カラーコードを覚えるコツ

🎯 キリの良い数字を覚える
  • #000、#333、#666、#999、#CCC、#FFF
  • 3桁表記は2桁ずつ展開される（#333 → #333333）
📊 16進数の対応関係

16進数の0〜F は、10進数の0〜255に対応します

  • #000000 = rgb(0, 0, 0)
  • #808080 = rgb(128, 128, 128)
  • #FFFFFF = rgb(255, 255, 255)
⚡ 便利な使い分け
  • テキスト：#000、#333（濃いめ）
  • 補助テキスト：#666、#999（中間）
  • 背景・ボーダー：#CCC、#EEE、#F5F5F5（明るめ）
